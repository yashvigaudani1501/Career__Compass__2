# 🚀 ATS Tracker - API Documentation

**Base API URL:** `http://localhost:5050/api`

---

## 🟢 1. Authentication Routes (Public)

### 1.1 Register a Normal User
*   **Method:** `POST`
*   **URL:** `/auth/register`
*   **Headers:** `Content-Type: application/json`
*   **Body:**
    ```json
    {
        "name": "Het Patel",
        "email": "het@example.com",
        "password": "password123"
    }
    ```
*   **Expected Response (201):** Returns User details + JWT Token.

### 1.2 Login (All Roles)
*   **Method:** `POST`
*   **URL:** `/auth/login`
*   **Headers:** `Content-Type: application/json`
*   **Body:**
    ```json
    {
        "email": "het@example.com",
        "password": "password123"
    }
    ```
*   **Expected Response (200):** Returns User details, Role (`USER`, `COMPANY`, `ADMIN`), and JWT Token. *(Save this token in React `localStorage`!)*

---

## 🔴 2. Admin Routes (Requires ADMIN Token)

### 2.1 Create Company (Triggers AI Web Scraper)
*   **Method:** `POST`
*   **URL:** `/admin/create-company`
*   **Headers:** 
    *   `Content-Type: application/json`
    *   `Authorization: Bearer <ADMIN_TOKEN>`
*   **Body:** *(Note: `work` and `companyInfo` are auto-generated by AI if `website` is provided!)*
    ```json
    {
        "name": "Stripe",
        "email": "hr@stripe.com",
        "password": "stripepassword123",
        "location": "San Francisco, CA",
        "website": "https://stripe.com"
    }
    ```
*   **Expected Response (201):** Returns Company Auth details + AI Generated Profile details.

---

## 🟠 3. Company Routes (Requires COMPANY Token)

### 3.1 Post a New Job
*   **Method:** `POST`
*   **URL:** `/company/post-job`
*   **Headers:** 
    *   `Content-Type: application/json`
    *   `Authorization: Bearer <COMPANY_TOKEN>`
*   **Body:**
    ```json
    {
        "title": "Full Stack Developer",
        "description": "Looking for a skilled developer.",
        "requiredSkills": ["React", "Node.js", "MongoDB", "Python"],
        "location": "Mountain View, CA (Hybrid)",
        "salary": "$120,000 - $150,000",
        "experienceLevel": "Mid Level"
    }
    ```
*   **Expected Response (201):** Returns the created Job object.

### 3.2 View Job Applicants (Sorted by AI ATS Score)
*   **Method:** `GET`
*   **URL:** `/company/applicants/:jobId` *(Replace `:jobId` with actual ID)*
*   **Headers:** `Authorization: Bearer <COMPANY_TOKEN>`
*   **Expected Response (200):** 
    Returns Job Title, Total Applicants count, and an array of `applications` containing Applicant Details (Name, Email) and AI Resume Data (Score, Skills).

---

## 🔵 4. User Routes (Requires USER Token)

### 4.1 Update User Profile
*   **Method:** `PUT`
*   **URL:** `/user/profile`
*   **Headers:** 
    *   `Content-Type: application/json`
    *   `Authorization: Bearer <USER_TOKEN>`
*   **Body:**
    ```json
    {
        "profession": "Frontend Developer",
        "skills": ["React", "JavaScript", "HTML"],
        "description": "Passionate UI developer.",
        "profileImage": "https://i.postimg.cc/test.jpg"
    }
    ```
*   **Expected Response (200):** Returns updated profile data.

### 4.2 Fetch All Available Jobs
*   **Method:** `GET`
*   **URL:** `/user/jobs`
*   **Headers:** `Authorization: Bearer <USER_TOKEN>`
*   **Expected Response (200):** Array of all active jobs, including the company name and email.

### 4.3 Upload Resume & Get AI Analysis
*   **Method:** `POST`
*   **URL:** `/user/upload-resume`
*   **Headers:** `Authorization: Bearer <USER_TOKEN>`
*   **Body Type:** `multipart/form-data` *(In React, use `new FormData()`)*
    *   **Key:** `resume` (Type: File)
    *   **Value:** [Select PDF File]
*   **Expected Response (200):** 
    ```json
    {
        "message": "Resume analyzed successfully by AI!",
        "data": {
            "resumePath": "uploads/...",
            "atsScore": 80,
            "extractedSkills": ["React", "Node.js"],
            "aiSuggestedJobs": ["Full Stack Developer"]
        }
    }
    ```

### 4.4 Apply for a Job
*   **Method:** `POST`
*   **URL:** `/user/apply/:jobId` *(Replace `:jobId` with actual Job ID)*
*   **Headers:** `Authorization: Bearer <USER_TOKEN>`
*   **Body:** None required.
*   **Expected Response (201):** `"Successfully applied for the job!"`
